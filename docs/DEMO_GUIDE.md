## Step-by-Step Demonstration Steps

### 1. Welcome Page & Role-Based Login (0:00 – 1:30)
- Navigate to the web application. Show the glassmorphic futuristic landing page.
- Sign in as Teacher (`teacher@example.com` / `TeacherPassword123!`).
- Highlight role-specific navigation tabs (Teaching, Classes, Planner, Analytics, AI Copilot).

### 2. Classroom Stream & Roster (1:30 – 3:00)
- Click into a Classroom (e.g. "Advanced Software Engineering").
- Show the unique 6-character Join Code.
- Post an Announcement with rich markdown formatting and view real-time comments.

### 3. Classwork Creation with Rubrics (3:00 – 4:30)
- In the **Classwork** tab, create an assignment with attached reference files.
- Add Rubric grading criteria (e.g. "Architecture Quality: 40 pts", "Test Coverage: 60 pts").
- Click "Publish". Show the real-time notification generated.

### 4. Student Experience & AI Study Assistant (4:30 – 6:00)
- Switch to a student session in an incognito window (`student@example.com`).
- View the new assignment in the **Stream** and **Classwork** tab.
- Click **AI Study Assistant** in the floating drawer.
- Ask: *"Can you summarize the architecture requirements for this assignment?"*
- Show instant context-aware summarization from uploaded classroom documents.
- Submit the assignment with text answers and uploaded files.

### 5. Plagiarism Engine & Originality Inspection (6:00 – 7:30)
- Switch back to Teacher window.
- Open **Plagiarism Dashboard** under the assignment.
- Click **"Analyze Submissions"**.
- Show deterministic similarity metrics, 3-gram matches, and phrase overlaps.
- Highlight peer student privacy masking ("Classroom Peer").

### 6. Live Virtual Classroom & Collaborative Whiteboard (7:30 – 9:00)
- Instructor clicks **"Start Live Class"**.
- Student joins the running session.
- Demonstrate WebRTC video/audio, real-time in-class chat, hand raising, and vector canvas whiteboard.
- End the live class and show automatic **Attendance 2.0** calculation.

### 7. Attendance Matrix & Analytics (9:00 – 10:30)
- View the **Attendance Intelligence** matrix with 75% early-warning threshold badges.
- Navigate to **Analytics 2.0** to inspect classroom grade distribution charts and at-risk student indicators.
- Download the sanitized CSV export report.

### 8. React Native Mobile Application (10:30 – 12:00)
- Open the mobile client on an Android/iOS emulator.
- Demonstrate native bottom-tab navigation, dark theme cards, and mobile assignment turn-in flow.
